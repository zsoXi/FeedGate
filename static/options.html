Policy / version 2

Promotion is not a verdict.

Useful detail is a reason to be cautious about hiding, not proof that a claim is true. Presets change explicit rules; no hidden author reputation is learned.

Protection and context

Balanced

Gentler profiles do not exempt explicit ads, your own exclusion rule or concrete fraud-like solicitation. Truncated semantic content is normally dimmed rather than collapsed.

Noise rules

This is your explicit preference. Enable “Your exclusion rule” above to use it. It can override useful-content protection. A non-empty criterion is sent with cloud requests even when its action is Off; clear the text to stop sending it. Never put secrets in this field.

Inference controls

Changing thresholds reuses cached feature scores and reapplies the policy. Changing the model, rubric or personal question invalidates the corresponding cache key. Requests, including failed attempts, can be billed.

Direct HTTPS / no bridge

A direct connection to Jev.

Only the trusted extension worker uses the key to call TypeSafe. Content scripts do not receive it. Nothing is sent by saving a key unless cloud analysis has separately been enabled.

Save or replace a key

Without the encrypted copy, the key lasts only for the Chrome session. A vault password is not stored or recoverable. Losing it means entering your API key again.

Unlock your saved key

Explicit cloud consent

No cookies, passwords, screenshots or image/video files are requested. Known private routes and editors are excluded. These guards cannot recognise every sensitive post. Best-effort redaction does not guarantee anonymity. TypeSafe has its own processing and retention terms.

An unlocked key is not protected from malware, a compromised extension update or someone controlling your computer. Use a dedicated key and revoke it if compromised.

Verify the actual provider

One fictional builder post, one real API request. A schema-valid response verifies transport, not classification accuracy.

Allowed authors

Saved post choices

“Keep this post” remembers a hash of the specific visible post, not a training label for the author. Edited content is evaluated again. Up to 2,000 choices stay on this device.
