FeedGate 2.1.0 / personal-use preview

No terminal.
No pairing.

A ready-made Chrome extension. The TypeSafe connection happens directly from the browser. Do not run the old START-FEEDGATE.cmd. You do not need Node, Python or a local server.

1Extract the whole package

Choose a permanent folder, for example D:\FeedGate-2.1.0. Do not run the extension directly from the ZIP. The folder must stay on disk after installation.

2Load the extension folder

In the Chrome address bar, type chrome://extensions. Enable Developer mode, click Load unpacked and select the extension subfolder. This is where manifest.json lives.

Chrome 120 or later is required. If an administrator blocks extension installation, do not work around that block.

3Key, consent, Connect & start

Open the FeedGate settings. In the Connect once and start browsing form, paste your direct TypeSafe API key. Tick the consent to send extracted post text to TypeSafe, leave X selected and click Connect & start. Accept the Chrome permission for that platform.

The extension makes one real request on a fictional post and then starts filtering. That test may be billed according to the provider's pricing.

Do not paste the key into a chat. A Vercel Gateway key and the old pairing code do not replace a TypeSafe key.

4Refresh X and scroll

After removing an older add-on, refresh the open X tab. Start with Balanced mode. A small page badge shows detected items, pending analysis and filtering. A project promotion on its own does not cause hiding.

Show restores a post temporarily. Keep this post stores an exception for that entry. Allow author adds the author to the local exception list. Alt + Shift + F reveals posts in the tab.

What about after a Chrome restart?

By default the key is available only in the browser session. To avoid retyping the key, tick Save an encrypted copy on this device and set your own passphrase, at least 12 characters. After a Chrome restart you unlock it with that passphrase in API & privacy.

There is no terminal and no new pairing code. The vault passphrase is not stored or recovered. Losing the passphrase means entering the key again.

When something does not work

Open Diagnostics → Export diagnostics. This produces a JSON file with counters, adapter state and safe error codes. It contains no key, post text or author names. Review the file before sharing it, especially publicly.

Observe only mode records intended decisions without hiding. Jev errors do not create a hide decision; independent local rules can still act.

Scope of this release

X and Reddit are the primary adapters. LinkedIn, Facebook and Instagram are experimental. Text and available media descriptions are analysed, not images or videos. This is a feed appearance filter, not a full network blocker.

99 Node tests and 31 Chromium DOM/UI scenarios passed. API responses and extension interfaces were controlled in tests. No test used a real key, a signed-in feed or a natively installed add-on in the build environment. The effectiveness of the new classification still needs checking on real posts.
